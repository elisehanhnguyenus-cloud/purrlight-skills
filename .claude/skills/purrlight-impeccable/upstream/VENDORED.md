**Not vendored, on purpose.**

| Left out | Why |
|---|---|
| `scripts/` (`impeccable` launcher, live-browser JS, font index) | The launcher downloads and runs a 21 MB engine binary. Every network call, all telemetry (on by default), update checks and the hooks live in that binary. |
| `.claude/settings.json` | SessionStart, PostToolUse and Stop hooks. |
| `.claude/agents/*`, `plugin/`, `cli/`, `crates/`, the other harness folders | Agents, plugin and installer code. |
| `reference/live.md`, `live-setup.md`, `generate.md` | Need the binary. Live mode spawns `claude --permission-mode bypassPermissions`. |
| `reference/hooks.md`, `doctor.md` | Engine admin. |
| `reference/component-review.md`, `region-map.md`, `visualize.md` | Engine-only steps. |
| `reference/degraded/asset-producer.md`, `manual-edit-applier.md` | Engine-only steps. |
| `reference/ios.md`, `android.md`, `adapt.native.md`, `audit.native.md` | Native apps only. |

The upstream hooks are guarded by `[ ! -f "$CLAUDE_PROJECT_DIR/.claude/skills/impeccable/scripts/impeccable" ] ||`. Never
create `.claude/skills/impeccable/` and never run `npx impeccable` (install, update, telemetry or detect). Either
would bring back the engine, the hooks and default-on telemetry.
